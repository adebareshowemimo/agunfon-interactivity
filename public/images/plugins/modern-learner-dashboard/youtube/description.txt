Your learners log in to Moodle... then what? Modern Learner Dashboard gives every learner one home — courses, progress, due dates, grades, badges and certificates in a single Moodle Dashboard block.

▶ WHAT IT DOES
• One tabbed block on the Dashboard: overview stats, Continue learning, Course Library, My courses, Calendar, Grades, Badges, Certificates and Profile
• Continue learning surfaces recently-accessed courses with progress bars and one-click resume
• A searchable, filterable Course Library learners can self-enrol from
• A built-in monthly calendar plus a due-soon count so deadlines don't slip
• Earned badges and Course Certificates, plus a learning transcript of every completed course — audit-ready
• Learners edit their own profile inline (name, picture, custom fields) — fewer profile tickets for your team
• Runs on core Moodle only: no external service, no new database tables, no cron

✅ WHY IT'S DIFFERENT
The default Moodle Dashboard scatters courses, grades, the calendar and the profile across separate pages. Modern Learner Dashboard pulls them into one fast, theme-aware, privacy-clean block — with nothing new to host.
