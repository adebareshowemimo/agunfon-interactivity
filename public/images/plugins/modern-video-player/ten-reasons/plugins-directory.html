Modern Video Player

Modern Video Player turns an ordinary video into a controlled, Moodle-native activity with playback validated on the server — so completion and watch-time actually mean something.

On that foundation it adds engagement heatmaps and a cohort dashboard, signed-URL and segmented-HLS delivery with dynamic watermarking, cloud and provider sources, seven branded player skins, learner aids like resume, chapters, transcript and captions, and audit-ready exports.

10 reasons to choose Modern Video Player

All features

Playback, completion and integrity

  • Server-validated watch-time, max-verified position and heartbeat tracking
  • Forward-seek guard with configurable grace seconds and suspicious-seek flags
  • Complete by watched percentage (default 95%) or validated end-of-video
  • Gradebook integration with a grade-to-pass threshold

Learner experience

  • Resume exactly where the learner left off; bookmarks with labels
  • WebVTT chapters, searchable transcript panel with download, multi-language captions
  • Playback speed with a max-speed cap, rewind, Picture-in-Picture, fullscreen
  • Autoplay options, poster image, next-activity overlay, keyboard shortcuts with help dialog

Engagement analytics and reporting

  • Per-activity engagement heatmap and audience-retention curve
  • Viewers-per-moment with drop-off and rewatch peaks
  • Site-level cohort dashboard aggregating every activity, with a cohort filter
  • Scheduled engagement digests emailed to instructors
  • Audit export as CSV, JSON, Excel or ODS, with per-learner integrity records

Content protection

  • Signed, user-bound video URLs that expire
  • Segmented HLS delivery — every segment individually signed, so no single URL yields the whole video
  • Dynamic name/email watermark overlay
  • Prevent download: blocks right-click save and drag-out, per activity
  • Screen-capture deterrence with a tamper-evident, hash-chained audit log

Sources and delivery

  • File upload, external direct URL (MP4/WebM), YouTube and Vimeo
  • Cloud storage: S3-compatible (AWS S3, Cloudflare R2, Wasabi, Spaces, B2, MinIO) and Azure Blob
  • Short-lived signed delivery from your own bucket; admin source-policy guardrails

Appearance and focus mode

  • Seven player styles: YouTube, Vimeo, Netflix, Plyr, Apple, Classic and Minimal
  • Per-activity style choice with an admin-set default, title position, control-text toggle
  • Focus mode hides navigation, course index and right blocks; auto-pause on hidden tab

Standards, platform and trust

  • xAPI statements (initialized, completed, flagged) to any LRS
  • LTI 1.3 Advantage publishing via core enrol_lti; activity events and logs
  • Privacy API (GDPR) — declares every learner data point stored
  • Full backup and restore of activities, files and progress
  • No dependencies, no Composer, no encoder: installs and works out of the box
