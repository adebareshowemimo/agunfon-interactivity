# Cover images (marketplace carousel)

On-brand cover images for the plugin's **Plugins Directory image carousel**. Upload them in the
order below — the **first image is the lead** buyers see, so it must be the strongest hook.

## Aspect ratio
- Carousel ratio: **16:9**  ·  8/8 covers match.
- ℹ Not 3:2. proven-patterns.md #7 recommends 3:2 for marketplace covers; a consistent ratio matters most.

## Reminders
- **Show the real product** — the screenshot is the hero of each cover; the headline is a strip, not a wall (proven-patterns #7).
- **Anonymise** every screenshot: no real names, emails, or customer data.
- moodle.org enforces no fixed size; **consistency + high resolution** is the rule. These render at 2× (2400×1600).
